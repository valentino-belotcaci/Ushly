## Preserved work and decisions

- SHA-256 comparisons verified both original SVG logos, all twelve original PNG
  icons and the pre-existing `backend/.env.example` edit are unchanged.
- The existing `frontend/.nvmrc` remains byte-for-byte unchanged.
- No existing explanatory comments were removed.
- Production dependencies are limited to the four approved packages:
  `react`, `react-dom`, `react-router`, and
  `@fontsource-variable/plus-jakarta-sans`. All tooling is development-only;
  npm generated the lockfile. ESLint 10 matches the maintained backend major.
- Native modal behavior, ordinary React state/context, semantic HTML and CSS
  variables keep the implementation small and explainable. Theme storage holds
  only a validated appearance preference. Primary orange has a dark foreground
  and light-mode supporting text uses a darker orange for contrast.
- No credentials, migrations, backend configuration, or new environment variables
  are required. No commits were made.
